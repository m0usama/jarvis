Now for your learning moment on data modelling, specifically star schemas and data build tool. In data engineering, a star schema is a mature database design pattern used for dimensional data warehousing. It separates data into fact tables, which store quantitative metrics like sales amounts or print quantities, and dimension tables, which store descriptive attributes like customer names, product categories, or dates. This structure makes analytical queries fast and easy to write because it avoids complex, multi-table joins. Data build tool, or dbt, is an open-source command line tool that allows data engineers to transform data in their warehouse by writing modular SQL select statements. Instead of managing messy procedural scripts, dbt treats SQL queries as version-controlled code, handling dependency graphs and table materialisations automatically. For example, in an e-commerce analytics pipeline, you might have a raw orders table. Using dbt, you build staging models to clean types and names, then build a dimensional model with a fact orders table linked to dimension tables for products and customers. This shows up in real engineering work whenever a company needs reliable, reproducible reporting metrics that business stakeholders can trust without digging through messy operational databases.
