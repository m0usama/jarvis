Learning Moment: Function Calling

  • Large language models cannot run code, query live databases, or call external APIs independently.
  • You provide the model with tool definitions using JSON schemas that outline function names, purposes, and parameter types.
  • The model outputs structured JSON with function arguments instead of standard text when external data is needed.
  • Application code intercepts the JSON, runs the native local code, and returns the result to the model for its final response.
  • Keeps execution safe within deterministic code rather than trusting the model with business logic.
  • Example: A user asks for the status of job card 482; the model calls a `get_job_status` tool with ID `482`, your Python script queries the local SQL database, and returns the string confirming it is in preflight.
