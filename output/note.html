Learning Moment: Agent Loop (Plan, Act, Observe)

  • An architectural pattern where an LLM repeatedly decides actions based on environmental feedback rather than running a rigid script.
  • Plan: The model reviews the goal and past actions to select the next tool to call.
  • Act: Code executes the tool call (e.g., querying databases, parsing images, or writing files).
  • Observe: Code feeds the tool output back to the model as context.
  • Requires guardrails like strict timeouts, fallback branches, and step logging to prevent infinite loops and cost spikes.
  • Example: Tasking an agent to format a menu where it plans to parse text, acts by running the parser, observes a missing price field, and updates its plan to run a targeted cleanup tool.
