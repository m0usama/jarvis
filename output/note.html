Learning Moment: Function Calling

  • Language models only output text natively and cannot directly access databases, file systems, or webhooks.
  • Tool use (function calling) provides the model with JSON schema descriptions of available functions, including names, arguments, and parameter types.
  • When external interaction is required, the model pauses generation and returns a structured JSON payload specifying the function and parameters instead of static text.
  • Your backend executes the actual code with those arguments, returns the result to the model, and the model generates the final response.
  • Provides deterministic, schema-validated inputs for agentic workflows rather than fragile string parsing via regular expressions.
  • Example: A user asks for the status of job 48; the model emits a structured call for `get_job_status(job_id=48)`, the Python backend queries the database showing it is on the press, and the model returns an accurate, real-time update to the user.
