Learning Moment: Cloud Deployment Options for Small Services

  • Choosing where to host involves balancing operational overhead, cost, and architectural control.
  • Fully managed PaaS (Render, Railway, Fly.io) handles provisioning, TLS certificates, and commit rebuilds with minimal overhead.
  • Serverless container platforms (AWS App Runner, Google Cloud Run, Azure Container Apps) scale automatically and charge only for active compute time.
  • Raw virtual machines (AWS EC2, DigitalOcean Droplets) offer absolute OS control but require manual maintenance, security patching, and process management.
  • Small production services typically start on serverless container platforms or lightweight PaaS.
  • Example: Standardising your FastAPI service inside a lean Docker container allows you to move seamlessly between Google Cloud Run or a managed container host without changing application code.
