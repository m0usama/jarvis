Learning Moment: Testing Strategy for Data and AI Code

  • Testing cannot be an afterthought when handling non-deterministic responses, external API downtime, and data anomalies.
  • A robust strategy uses three layers: unit tests with mocking, data validation tests, and evaluation assertions.
  • High-performing teams test deterministic parsing and fallback handling on mocked services in CI, avoiding live API calls.
  • Example: In the job card print automation, use pytest and unittest.mock to mock the vision client with three fixed payloads (valid, malformed missing customer name, empty), asserting parsing succeeds or catches errors gracefully without hitting the live model or sheets.
