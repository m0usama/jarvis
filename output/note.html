Learning Moment: Workflow Orchestration

  • Cron runs isolated tasks at fixed intervals but operates blind without dependency handling, state awareness, or automatic retries.
  • Modern orchestrators like Airflow and Prefect manage pipelines as Directed Acyclic Graphs (DAGs), breaking workflows into dependent tasks.
  • Orchestrators provide automatic retries with backoff, state caching, execution dashboards, and failure alerting.
  • Production engineering requires orchestration for unattended reliability and clear post-mortem logs.
  • Example: In a catalogue enrichment pipeline, task one fetches supplier data, task two parses schema, task three updates the database, and task four sends an alert; if task two fails, downstream tasks pause and retry using cached data from task one.
