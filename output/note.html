Learning Moment: Fine-Tuning vs. Retrieval-Augmented Generation vs. Prompting

  • Prompt engineering alters instructions within the context window; instant and zero-compute, but limited by context size.
  • RAG injects dynamic external knowledge into the prompt at runtime for frequently updated data and strict source attribution.
  • Fine-tuning adjusts model weights to teach behavior, style, and syntax, but does not reliably inject factual knowledge.
  • In practice: prompt first for feasibility, add RAG for dynamic private data, and fine-tune for complex syntax or small open model execution.
  • Example: Use RAG to query print catalogues or stock levels, and fine-tune a smaller model to deterministically output bespoke InDesign markup without verbose system prompts.
