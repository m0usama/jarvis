Learning Moment: Retrieval Augmented Generation (RAG)

  • RAG injects external context into prompts before model generation to eliminate outdated knowledge and access private data without retraining.
  • The ingestion phase cleans text, splits it into chunks, converts chunks into mathematical embedding vectors, and stores them in a vector database.
  • The retrieval phase converts a query into an embedding vector, performs a similarity search, and passes the matching text chunks to the model.
  • Real-world quality relies heavily on chunking strategies, retrieval evaluation, and handling missing context.
  • Example: Converting unformatted trade catalogue PDFs into chunked vector embeddings so an LLM can answer spec questions strictly using retrieved text blocks.
